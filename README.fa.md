# ZX VPN

**همهٔ راه‌های اتصال، در یک برنامه.**

[English](README.md) · **فارسی**

ZX VPN یک کلاینت چند‌هسته‌ای VPN و پروکسی است.

> وضعیت پروژه: در دسترس بودن هسته‌ها به سیستم‌عامل، نوع بیلد و نسخه بستگی دارد. پیش از اتکا به یک هسته، توضیحات همان نسخه را بررسی کنید.

## GHOST MOD

GHOST MOD سیستم پیشرفته ضدسانسور ZX است: دفاع چندلایه در برابر DPI با داشبورد وضعیت زنده.

- **لایه‌ها:** تشخیص و وضعیت → استتار نرم (Reality + uTLS + XHTTP + Fragment) → دسینک سخت → شکل‌دهی آماری → نردبان تطبیقی → مسیر جایگزین (Hysteria2 / AmneziaWG / DNS / Psiphon / Tor)
- **وضعیت:** سطح DPI، نوع تشخیص، آخرین تست به وقت ایران، دیده‌شدن (نامرئی / تحت فشار / در حال تطبیق)
- **پروفایل‌ها:** `iran_mobile`، `iran_home`، `russia`، `china`، `auto`، `custom`
- **ضد پورن** (بدون تغییر): DNS خانوادگی + مسدودسازی دامنه/کلیدواژه + بستن DoH

جزئیات فنی: [docs/GHOST_MODE_ADVANCED.md](docs/GHOST_MODE_ADVANCED.md)
